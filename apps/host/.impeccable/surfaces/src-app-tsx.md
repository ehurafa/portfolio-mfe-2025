## Scope

Whole host site (Início, Projetos, Projeto, Sobre mim, Certificados, Laboratório). Mode: Persuade — a tech lead decides whether to interview.

## Audience and job

Recruiters and tech leads at a laptop, a few minutes between tasks. They need current role, stack and running projects fast, then a path to LinkedIn/GitHub. Nothing flashy.

## Direction contract

THESIS: The canon senior-dev portfolio at brittanychiang.com's craft level: a fixed identity column beside a readable content column. Refuses hero slogans, icon-card grids, gradient text, glass and neon.

OWN-WORLD: Deep slate ground, slate-400 body, slate-200 headings, one calm teal accent for links, active nav and tech pills. Inter throughout. Content as rows that light up on hover, no card borders. Nav items carry a rule that stretches when active.

STORY: The visitor sees name, role, current employer and stack at once, opens a running project or its code in one click, reads the timeline, leaves via LinkedIn or GitHub.

FIRST VIEWPORT: Desktop: left column (sticky, full height) with avatar, brand logo, "Front-end Developer", one-line pitch, vertical nav, social icons pinned at the bottom. Right column: intro paragraphs naming Ouribank and React/Vue/Angular, then featured project rows with "Abrir" and "Código" links. Mobile: identity stacks on top with a menu toggle.

FORM: canon (standing exit, reference brittanychiang.com); seed 0d8f0145. Signature interaction: the nav rule stretch plus row highlight with arrow nudge. Motion grammar: one fade-up per route change, exponential ease-out, disabled under reduced motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
